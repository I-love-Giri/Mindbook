This function is a **retry helper**. It repeatedly tries to run some code, and if it fails, it waits and tries again with a longer delay each time (**exponential backoff**).


```python
def _retry(func, retries: int = 3, base_wait: float = 1.0):
```

### What it means

Defines a function named `_retry`.

Parameters:

* `func` → a function you want to execute.
* `retries=3` → maximum number of attempts.
* `base_wait=1.0` → initial wait time in seconds.

Example:

```python
_retry(my_function)
```

This will try `my_function()` up to 3 times.

---

```python
"""Call *func* with exponential back-off. Raises last exception on exhaustion."""
```

This is the docstring (documentation).

Meaning:

* Call the function.
* If it fails, wait and retry.
* Waiting time grows exponentially.
* If all attempts fail, raise the last error.

---

```python
last_exc: Exception = RuntimeError("No attempts made")
```

Creates a variable called `last_exc`.

Initially it stores:

```python
RuntimeError("No attempts made")
```

Why?

Because if something goes wrong before any retry happens, there's still an exception object available.

Example:

```python
last_exc = RuntimeError("No attempts made")
```

---

```python
for attempt in range(retries):
```

Loop through retry attempts.

If `retries = 3`:

```python
range(3)
```

produces:

```python
0
1
2
```

So there will be 3 attempts.

| attempt | Attempt number |
| ------- | -------------- |
| 0       | 1st try        |
| 1       | 2nd try        |
| 2       | 3rd try        |

---

```python
try:
```

Start a block where Python watches for errors.

---

```python
return func()
```

Call the function.

Example:

```python
def say_hi():
    return "Hello"

_retry(say_hi)
```

Execution:

```python
func()
```

returns:

```python
"Hello"
```

The `_retry()` function immediately returns `"Hello"`.

No retries are needed.

---

```python
except Exception as exc:
```

If `func()` raises any exception:

Example:

```python
def bad():
    raise ValueError("Something failed")
```

Then:

```python
exc
```

contains:

```python
ValueError("Something failed")
```

---

```python
last_exc = exc
```

Save the latest exception.

Example:

```python
last_exc = ValueError("Something failed")
```

This is useful because after all retries fail, the code will raise the last error encountered.

---

```python
wait = base_wait * (2 ** attempt)
```

Calculate how long to wait before retrying.

This is the **exponential backoff** formula.

If:

```python
base_wait = 1
```

Then:

### Attempt 1

```python
attempt = 0

wait = 1 * (2 ** 0)
     = 1 * 1
     = 1 second
```

### Attempt 2

```python
attempt = 1

wait = 1 * (2 ** 1)
     = 2 seconds
```

### Attempt 3

```python
attempt = 2

wait = 1 * (2 ** 2)
     = 4 seconds
```

So waits become:

```text
1s → 2s → 4s
```

This is called exponential backoff.

```python
logger.debug(
```

Write a debug log message.

This doesn't affect program execution; it's just information for developers.

---

```python
"Attempt %d/%d failed (%s); retrying in %.1fs",
```

The message template.

Example output:

```text
Attempt 2/3 failed (ConnectionError); retrying in 2.0s
```

---

```python
attempt + 1, retries, exc, wait,
```

Values inserted into the placeholders.

Example:

```python
attempt = 1
retries = 3
exc = ConnectionError("Server down")
wait = 2
```

Produces:

```text
Attempt 2/3 failed (Server down); retrying in 2.0s
```

---

```python
time.sleep(wait)
```

Pause execution.

Example:

```python
time.sleep(2)
```

waits 2 seconds before continuing.

---

After sleeping, the loop runs again and retries the function.

---

```python
raise last_exc
```

If every retry fails, raise the final exception.

Example:

Suppose all 3 attempts fail:

```python
Attempt 1 -> ValueError
Attempt 2 -> ValueError
Attempt 3 -> ValueError
```

After the loop:

```python
raise last_exc
```

becomes:

```python
raise ValueError("Something failed")
```

So the caller sees the actual error.

---

## Complete Example

```python
count = 0

def flaky():
    global count
    count += 1

    if count < 3:
        raise Exception("Temporary failure")

    return "Success!"
```

Call:

```python
result = _retry(flaky)
print(result)
```

### Execution

#### First attempt

```python
count = 1
```

Raises:

```python
Exception("Temporary failure")
```

Wait:

```python
1 second
```

---

#### Second attempt

```python
count = 2
```

Raises:

```python
Exception("Temporary failure")
```

Wait:

```python

```

---

#### Third attempt

```python
count = 3
```

Returns:

```python
"Success!"
```

Output:

Success!

In short, `_retry()` is a reusable wrapper that makes unreliable operations (API calls, database queries, network requests, etc.) more resilient by automatically retrying them with increasing delays.
