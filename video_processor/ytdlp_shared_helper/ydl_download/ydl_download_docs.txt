This function is a small wrapper around the **yt-dlp** library that downloads a video (or other media) from a URL and raises an error if the download fails.

Here's the code again:

```python
def _ydl_download(url: str, opts: dict) -> None:
    """Run yt-dlp download; raise RuntimeError on non-zero exit code."""
    import yt_dlp
    with yt_dlp.YoutubeDL(opts) as ydl:
        code = ydl.download([url])
    if code != 0:
        raise RuntimeError(f"yt-dlp exited with code {code}")
```

creates and safely closes the downloader object.

## Line 5: Download the URL

```python
code = ydl.download([url])
```

ydl.download([...]) is the line that actually starts the download process and saves the media file to disk according to the options in opts.

### What happens?

Calls yt-dlp's `download()` method.

Notice:

```python
[url]
```

The URL is wrapped inside a list.

Even if there is only one URL:

```python
["https://youtube.com/watch?v=abc123"]
```

because `download()` expects a list of URLs.

### Example

Suppose:

```python
url = "https://www.youtube.com/watch?v=abc123"
```

Then:

```python
code = ydl.download([url])
```

becomes:

```python
code = ydl.download([
    "https://www.youtube.com/watch?v=abc123"
])
```

---

## What is stored in `code`?

`download()` returns an exit code.

Typically:

```python
0
```

means success.

Non-zero values mean some kind of failure.

Example:

```python
code = 0
```

means:

> Download completed successfully.

Example:

```python
code = 1
```

means:

> Something went wrong.

---

## Line 6: Check for Failure

```python
if code != 0:
```

Reads as:

> If the exit code is NOT zero...

Examples:

```python
code = 0
```

Condition:

```python
0 != 0
```

Result:

```python
False
```

No error.

---

Example:

```python
code = 1
```

Condition:

```python
1 != 0
```

Result:

```python
True
```

Error will be raised.

## Line 7: Raise an Exception

```python
raise RuntimeError(f"yt-dlp exited with code {code}")
```

If download failed, stop execution and raise a `RuntimeError`.

Example:

```python
code = 1
```

Produces:

```python
RuntimeError: yt-dlp exited with code 1
```

Example:

```python
code = 5
```

Produces:

```python
RuntimeError: yt-dlp exited with code 5
```

The `f` before the string means **f-string** formatting.

```python
f"yt-dlp exited with code {code}"
```

If:

```python
code = 7
```

becomes:

```python
"yt-dlp exited with code 7"
```

# Complete Flow Example

Suppose:

```python
url = "https://www.youtube.com/watch?v=abc123"

opts = {
    "format": "best"
}
```

Call:

```python
_ydl_download(url, opts)
```

Internally:

### Step 1

Create downloader

```python
ydl = yt_dlp.YoutubeDL(opts)
```

### Step 2

Download

```python
code = ydl.download([url])
```

Suppose success:

```python
code = 0
```

### Step 3

Check

```python
if code != 0:
```

becomes:

```python
if 0 != 0:
```

False.

### Step 4

Function ends successfully.

---

### Failure Scenario

Suppose the URL is invalid.

```python
code = 1
```

Then:

```python
if 1 != 0:
```

True.

Python executes:

```python
raise RuntimeError(
    "yt-dlp exited with code 1"
)
```

Result:

```text
RuntimeError: yt-dlp exited with code 1
```

and the program stops unless you catch the exception.

Example:

```python
try:
    _ydl_download(url, opts)
except RuntimeError as e:
    print("Download failed:", e)
```

Output:

```text
Download failed: yt-dlp exited with code 1
```

### In one sentence

This function creates a yt-dlp downloader using the given options, downloads the provided URL, and raises a `RuntimeError` if yt-dlp reports that the download failed.
